# Changelog

## 1.0.0 — 2026-10-03

Initial public source release of lms omni gateway, derived from the Sonct/LM Studio
OpenAI-compatible endpoint generator.

- Twelve native provider profiles, including NVIDIA, Evren.ssyz, and Muskapi.cc.
- Per-chat Active Provider with shared provider connection/model fields.
- Model discovery, cached dropdown snapshots, image-capability metadata, and OpenRouter Free labels.
- Streaming Chat Completions, tools, final-answer token/model/time footer switches.
- Explicit DeepSeek/OpenRouter balance lookups and saved local status.
- Image commands in the LM Studio chat, with a Windows picker.
- Immediate cached registration before background API discovery.
- Synthetic/local tests, source installation guide, privacy notes, and upstream attribution.

Known host UI limits and unsupported features are documented in the README.
